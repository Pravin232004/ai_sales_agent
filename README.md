
# AI Sales Workforce Agent

An AI-powered sales automation system built with LLMs, RAG, AI agents,
tool calling, FastAPI, PostgreSQL, n8n, and React.

🚧 Under Development

- Retrieval-Augmented Generation (RAG)
- Vector search
- AI agent tool calling
- Lead management
- Calendar integration
- Email automation
- CRM integration
- n8n workflow automation
- PostgreSQL database
- FastAPI backend
- React frontend
